# VOLT ONE — сайт аренды электровелосипедов

Статический сайт. Страницы генерируются скриптом `build.py` (Python 3, без зависимостей).

## Как добавить фото модели
1. Положите фото в папку модели: `img/models/u2/`, `img/models/u2-big/`, `img/models/u5/`, `img/models/r9/`
   — по два файла на фото: `name.webp` и `name.jpg` (≤1600 px). Порядок — по алфавиту, первое фото = обложка.
2. Запустите `python3 build.py` и закоммитьте.

## Точки на карте
Список `POINTS` в `build.py`: при нескольких точках над картой автоматически появляются вкладки.
